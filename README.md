# Cedrick Nkurunziza (CK) — Portfolio

Live site: [my-portfolio-delta-eight-55.vercel.app](https://my-portfolio-delta-eight-55.vercel.app/)

Welcome! This is the source code for my personal portfolio website. I built it to share my work and projects spanning **Software Engineering, Computer Networks, and DevOps**.

It features a dark liquid-glass UI theme, dynamic 3D elements, and smooth interactions.

---

## Tech Stack

- **Frontend:** React 18, Vite
- **Styling & Animations:** Tailwind CSS, Framer Motion
- **3D & Visuals:** Three.js (`@react-three/fiber`, `@react-three/drei`)
- **Icons & Contact:** Lucide React, React Icons, EmailJS

---

## What's Inside

- **Hero:** Intro section with my profile picture, quick stats, and background 3D orb.
- **Skills Stream:** Infinite horizontal tech marquee (pauses when you hover).
- **Work Experience:** Career timeline featuring my current role in the **RwandAir IT / RISE Graduate Development Programme** alongside previous roles.
- **DevOps & Linux Projects:** Practical infrastructure labs covering Linux server admin, network defence, Suricata IDS, Docker containerization, and Traefik load balancing.
- **Featured Projects:** Full-stack applications with direct links to source code and live demos.
- **Education:** BS in Information Technology from Adventist University of Central Africa (AUCA).
- **Get In Touch:** Personal contact section linked directly to my email via EmailJS.

---

## Local Setup

```bash
# Clone the repository and navigate into the folder
cd My-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser to view the site.

To test the production build:
```bash
npm run build
npm run preview
```
